# Loans App

Backend application for managing informal loans, monthly interests, capital payments, and payment history.

## Technologies

- Node.js
- TypeScript
- PostgreSQL
- Docker
- pgAdmin
- Express

## Project Status

🚧 In development

## Run Docker Services

```bash
docker compose up -d
```

## Stop Services

```bash
docker compose down
```

## Environment Variables

Create a `.env` file based on `.env.example`.

## Database

PostgreSQL is available on:

```txt
localhost:5433
```

pgAdmin:

```txt
http://localhost:8081
```
